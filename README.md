# FocusForge

FocusForge is a modern productivity and career management dashboard designed to help students, developers, and job seekers organize tasks, manage interview pipelines, track productivity, and stay focused through Pomodoro sessions.

## Live Demo

https://focus-forge-nine-zeta.vercel.app/

## Portfolio

## Features

### Dashboard

* Productivity overview
* Task completion metrics
* Focus session tracking
* Interview application statistics
* Daily goal progress indicators

### Task Manager

* Create tasks
* Mark tasks as completed
* Delete tasks
* Real-time statistics
* Local storage persistence

### Pomodoro Timer

* 25-minute focus sessions
* 5-minute break sessions
* Session tracking
* Productivity enhancement workflow

### Interview Tracker

* Track job applications
* Update application status
* Manage interview pipeline
* Store company and role details
* Local storage persistence

### Analytics

* Productivity insights
* Goal tracking
* Workspace activity logs
* Performance metrics

### Settings

* User profile management
* Daily task goal configuration
* Pomodoro goal customization

## Tech Stack

### Frontend

* React.js
* Vite
* React Router DOM
* Tailwind CSS
* React Icons

### Storage

* LocalStorage API

### Deployment

* Vercel

## Installation

```bash
git clone https://github.com/Likhithpsdas17/FocusForge.git
cd FocusForge
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```
