# FocusForge

A modern productivity and interview tracking dashboard built using React.js and Vite.

## Features

* Dashboard Overview
* Task Management (CRUD)
* Pomodoro Timer
* Interview/Application Tracker
* Productivity Analytics
* User Settings
* Local Storage Persistence
* Responsive UI

## Tech Stack

* React.js
* Vite
* React Router DOM
* Tailwind CSS
* React Icons
* LocalStorage API

## Installation

```bash
git clone <repository-url>
cd focusforge
npm install
npm run dev
```

## Build

```bash
npm run build
```
